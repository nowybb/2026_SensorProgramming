뽀송연구회 스마트 신발장 모바일 웹 (현재 위치 기반 실제 날씨)

파일:
- index.html : 화면 구조
- style.css : CSS
- script.js : 신발장 및 관리자 UI 시연용
- weather.js : 브라우저 위치 권한 + Open-Meteo 실시간 날씨

실행:
1) 네 파일을 같은 폴더에 둡니다.
2) PC에서: python -m http.server 8000
3) 동일 PC의 브라우저에서 http://localhost:8000 으로 접속합니다.
4) 위치 권한 요청을 허용하면 해당 좌표의 실제 날씨를 불러옵니다.

주의:
- 스마트폰에서 위치 기능을 사용하려면 HTTPS로 호스팅해야 합니다. 단순 LAN IP의 http:// 주소에서는 대부분 위치 기능이 차단됩니다.
- 날씨 API 요청 또는 위치 확인이 실패하면 “날씨 데이터를 불러오지 못했습니다”가 표시됩니다.
- Open-Meteo: https://open-meteo.com/en/docs (일반 비상업적 사용에 API 키 불필요, 약관 확인)
- 위치 좌표는 브라우저에서 Open-Meteo로 전송되며 사이트의 로컬 저장소에는 저장하지 않습니다.
- 날씨는 외부 환경 정보입니다. 신발장 내부 온습도는 아직 가상 데이터입니다.

QR 첫 화면 사용법:
- 웹페이지 주소 끝에 ?cabinet=1 을 붙이면 1번 칸 QR 첫 화면이 열립니다.
- ?cabinet=2 를 붙이면 2번 칸 QR 첫 화면이 열립니다.
- 첫 화면에서 '내 신발장 확인하기'를 누르면 해당 칸 상세 페이지가 표시됩니다.
- 일반 주소(쿼리 없음)는 기존 홈 화면으로 이동합니다.
- 칸별 QR은 URL 이동 기능이며 사용자 인증을 대신하지 않습니다.
